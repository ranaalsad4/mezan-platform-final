# App v2 documentation

`Mezan_Learning_Guide.(docx|md)` and `learning.json` are the method notes for every analytical method (what it is, where it
comes from, how Mezan implements it). They remain valid as methodology documentation; references to Learning Mode,
the guided demo and the Learning Center describe the v2 interface, which app v3 replaced. Screenshots show v2.
`Mezan_MRC_Source_Register.(xlsx|csv)` is current. `TEST_RESULTS.md` records the v2.1 test run; v3 results are in
`docs/TEST_RESULTS_V3.md`.
